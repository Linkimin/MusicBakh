# MusicBakh

Настольный музыкальный плеер и библиотека для Windows. Хранит локальную коллекцию треков, читает теги, подтягивает обложки и жанры, проигрывает аудио со всеми привычными элементами управления.

## Возможности

- **Импорт треков** — добавление в библиотеку из локального файла (mp3/wav) или по прямой ссылке (до 50 МБ).
- **Воспроизведение** — Play/Pause, перемотка ±10 секунд, переход к следующему/предыдущему треку, активный seek-слайдер.
- **Громкость и mute** — отдельный слайдер 0–100% и кнопка беззвучного режима.
- **Режимы повтора** — без повтора / повтор текущего трека / повтор всей видимой библиотеки.
- **Три вида библиотеки** — вкладки **Треки / Альбомы / Исполнители** в шапке (`Ctrl+1`/`Ctrl+2`/`Ctrl+3`). Альбомы — сетка плиток с обложками, исполнители — список с аватарами. Клик открывает детальную страницу (drill-down), `Esc` возвращает назад. Кнопки «▶ Воспроизвести альбом» / «Слушать всё» и «🔀 Перемешать» на детальных страницах.
- **Плейлисты** — вкладка «Плейлисты» (`Ctrl+4`): создание и переименование прямо в списке, наполнение через контекстное меню «Добавить в плейлист ▸» или перетаскиванием (в том числе нескольких треков), перестановка треков перетаскиванием, Play/Shuffle. Один трек может стоять в плейлисте несколько раз.
- **Сборники (compilations)** — треки с тегом `AlbumArtist` (например, `Various Artists`) собираются в один альбом, при этом каждый исполнитель виден отдельно во вкладке «Исполнители».
- **Рейтинги 0–5★** — кликабельные звёзды под обложкой выбранного трека. Клик по горящей звезде сбрасывает рейтинг.
- **Реакция лайк / дизлайк** — ♥ и ♥̸ с мгновенным отображением состояния. Повторный клик сбрасывает.
- **Пользовательские теги-ярлыки** — создание, переименование и удаление тегов в отдельном окне (`Ctrl+G`). Привязка/открепление тега к треку в один клик. До 3 тег-чипов на карточке трека + золотая пилюля «+N».
- **Поиск по библиотеке** — мгновенный полнотекстовый поиск по названию, исполнителю, альбому, жанру (SQLite FTS5, дебаунс ~250 мс). Совмещается с фильтром по жанру. `Ctrl+F` фокусирует поле, `Esc` очищает.
- **Горизонтальный фильтр-toolbar** — поиск, жанр, тег-чипы с overflow и ⋮ popup с фильтрами рейтинга/реакции над списком треков. Список треков показывает ≥7 треков на дефолтном размере окна.
- **Экран статистики** — отдельное окно (`Ctrl+T` или кнопка «Статистика» в шапке) с вкладками **Топ-50**, **Недавние** (уникальные по последнему воспроизведению), **Ни разу не играли**.
- **Горячие клавиши** — `Space`: play/pause, `Shift+←`/`Shift+→`: перемотка ±10 с, `Ctrl+←`/`Ctrl+→`: предыдущий/следующий, `Ctrl+M`: mute, `Ctrl+R`: смена режима повтора, `Ctrl+F`: фокус на поиск, `Ctrl+T`: статистика, `Ctrl+G`: окно «Теги», `Ctrl+1`/`Ctrl+2`/`Ctrl+3`/`Ctrl+4`: вкладки Треки/Альбомы/Исполнители/Плейлисты, `Esc`: назад из drill-down.
- **Метаданные** — каскад «теги ID3 → очистка от мусорных суффиксов агрегаторов → MusicBrainz → имя файла». С 1.0.2 читается также `Album`.
- **Жанры на русском** — словарь из 50+ маппингов (`rock` → «Рок», `electronic` → «Электроника» и т. д.).
- **Обложки** — встроенная картинка ID3 → iTunes Search API (600×600) → процедурная заглушка с буквой исполнителя.
- **История воспроизведения** — виджет «недавнее» (последние 50 запусков, двойной клик переигрывает) + полный журнал на экране статистики.
- **Фильтр по жанру** — выпадающий список, автоматически собирается из библиотеки.
- **Сохранение и удаление** — экспорт выбранного трека в файл, удаление пользовательских треков с подтверждением.
- **Persistence** — громкость, mute и режим повтора восстанавливаются между запусками.
- **Сохранность данных** — перед обновлением схемы БД автоматически создаётся резервная копия; при ошибке старта данные не сбрасываются. Локальный журнал `musicbakh.log` для диагностики никуда не отправляется.

## Требования

| Сценарий | Что нужно |
|---|---|
| Запуск из инсталлятора | Windows 10 1809 (build 17763) или Windows 11, x64, ~200 МБ свободного места |
| Запуск из исходников | дополнительно [.NET 10 SDK](https://dotnet.microsoft.com/) |

Инсталлятор поставляется как self-contained сборка — отдельно ставить .NET-рантайм пользователю не нужно.

## Установка

1. Скачать `MusicBakh-Setup-X.Y.Z.exe` из раздела Releases.
2. Запустить. Windows SmartScreen может предупредить о неподписанном исполняемом файле — «Подробнее → Выполнить в любом случае».
3. Установщик ставит приложение per-user в `%LocalAppData%\Programs\MusicBakh` (UAC не требуется).

Пользовательские данные хранятся в:

- `%LocalAppData%\MusicLibrary\library.db` — SQLite-база с треками (с FTS5-индексом `TracksFts` начиная с 1.0.2), историей и настройками плеера (заменила `userTracks.json` начиная с 1.0.1).
- `%LocalAppData%\MusicLibrary\Music\` — импортированные аудиофайлы.
- `%LocalAppData%\MusicLibrary\Covers\` — обложки.
- `%LocalAppData%\MusicLibrary\userTracks.json.backup-<timestamp>` — резервная копия старого индекса, появляется только при первом запуске после апгрейда с 1.0.x; можно удалить вручную.

При деинсталляции каталог приложения удаляется полностью, пользовательские данные в `%LocalAppData%` сохраняются, чтобы переустановка восстановила библиотеку.

## Запуск из исходников

```powershell
git clone https://github.com/Linkimin/MusicBakh.git
cd MusicBakh
dotnet build
dotnet run --project MusicLibrary
```

Тесты:

```powershell
dotnet test
```

## Сборка релиза

```powershell
pwsh scripts/build-release.ps1 -Version 1.0.4
```

Скрипт публикует single-file self-contained сборку под win-x64 в `publish\win-x64\` и собирает установщик через Inno Setup в `release\MusicBakh-Setup-1.0.4.exe`. Подробности — в [docs/release-checklist.md](docs/release-checklist.md).

## Архитектура

WPF + лёгкий MVVM на .NET 10. Начиная с релиза 1.0.1 (итерация A эпика «Library 2.0») приложение разбито на 4 проекта: `MusicBakh.Core`, `MusicBakh.Application`, `MusicBakh.Infrastructure`, `MusicLibrary`. Хранение — SQLite через EF Core 10 (с 1.0.2 поверх лежит FTS5-индекс `TracksFts` для полнотекстового поиска). DI-контейнер — `Microsoft.Extensions.Hosting`; бутстрап выполняется в [`App.OnStartup`](MusicLibrary/App.xaml.cs). Полное описание слоёв и сервисов — [docs/architecture.md](docs/architecture.md).

Стратегическое видение продукта на 3 года вперёд — [docs/roadmap-vision.md](docs/roadmap-vision.md). Changelog по версиям — [docs/changelog/](docs/changelog/).
