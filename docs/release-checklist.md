# Чеклист релиза

Последовательность шагов для выпуска новой версии MusicBakh. Пройти от начала до конца до того, как ставить тег и публиковать установщик.

## 1. Подготовка кода

- [ ] Все изменения для версии слиты в `main`.
- [ ] `dotnet test` — все тесты зелёные.
- [ ] `dotnet build -c Release MusicLibrary/MusicLibrary.csproj` — собирается без предупреждений.
- [ ] Версия в [MusicLibrary.csproj](../MusicLibrary/MusicLibrary.csproj) обновлена (`<Version>`, `<AssemblyVersion>`, `<FileVersion>`).
- [ ] При необходимости — короткий CHANGELOG-абзац в commit-сообщении тега или отдельном `CHANGELOG.md`.

## 2. Ручной smoke на dev-машине

Гонится прямо `dotnet run --project MusicLibrary`. Проверить, что все кнопки работают:

- [ ] Импорт локального `.mp3` (через «＋ Добавить трек» → «Из файла»).
- [ ] Импорт по URL (через «＋ Добавить трек» → «По ссылке»).
- [ ] Play / Pause / Stop, перемотка ±10 с, переход к предыдущему/следующему.
- [ ] Активный seek-слайдер: клик по дорожке и перетаскивание.
- [ ] Слайдер громкости и кнопка mute.
- [ ] Переключение режима повтора: No → Current → Library.
- [ ] Удаление пользовательского трека: открывается кастомный `ConfirmationDialogWindow`, трек исчезает из библиотеки и из `userTracks.json`.
- [ ] Сохранение трека через «Сохранить» (`SaveFileDialog`).
- [ ] Двойной клик по карточке трека и по записи в истории — оба запускают воспроизведение.
- [ ] Фильтр по жанру.
- [ ] Поле «Поиск» фильтрует список треков, дебаунс ~250 мс, очистка возвращает полную библиотеку.
- [ ] Поиск + жанр совмещаются (только треки выбранного жанра среди результатов поиска).
- [ ] `Ctrl+F` фокусирует поле поиска и выделяет текст; `Esc` очищает.
- [ ] Кнопка «Статистика» и `Ctrl+T` открывают окно с тремя вкладками; `Esc` закрывает; окно не блокирует основное.
- [ ] Топ-50 показывает прослушанные треки с правильным счётчиком; Недавние — уникальные по последнему воспроизведению; Ни разу не играли — сокращается после прослушивания трека из этого списка.
- [ ] Горячие клавиши: `Space`, `Shift+←`/`Shift+→`, `Ctrl+←`/`Ctrl+→`, `Ctrl+M`, `Ctrl+R`, `Ctrl+F`, `Ctrl+T`.
- [ ] В поле поиска можно набирать русские «К» и «Ь» (раскладка ЙЦУКЕН не перехватывается хоткеями).
- [ ] Перезапуск приложения: громкость, mute и режим повтора восстановились из `%LocalAppData%\MusicBakh\player-settings.json`.
- [ ] Апгрейд с 1.0.1: запустить приложение с уже существующей `%LocalAppData%\MusicLibrary\library.db` — миграции `AddTrackAlbum` и `AddTracksFts` накатились без ошибок, треки на месте, поиск работает.
- [ ] Апгрейд с 1.0.2: миграции `AddTrackRatingAndReaction` и `AddTagsAndTrackTags` накатились без ошибок, существующие треки видны в библиотеке.
- [ ] Апгрейд с 1.0.3: миграция `AddTrackYearNumberAlbumArtist` накатилась без ошибок, существующие треки на месте (новые поля Year/TrackNumber/AlbumArtist = NULL до ре-импорта).
- [ ] Вкладки «Треки/Альбомы/Исполнители» переключаются кликом и `Ctrl+1`/`Ctrl+2`/`Ctrl+3`; активная подсвечена; средняя/правая колонки не двигаются; выбранная вкладка восстанавливается после перезапуска.
- [ ] Albums view: сетка плиток с обложками; клик открывает детальную страницу; кнопки «▶ Воспроизвести альбом» и «🔀 Перемешать» заменяют очередь и стартуют трек; «← Все альбомы» / `Esc` возвращают.
- [ ] Artists view: список с аватарами; клик открывает страницу исполнителя; под-сетка альбомов + «Прочие треки» (если есть); клик по альбому внутри → drill глубже; `Esc` возвращает на страницу исполнителя, следующий `Esc` — на список; «▶ Слушать всё» / «🔀 Перемешать» работают.
- [ ] Фильтры (поиск/жанр/тег/рейтинг/реакция) действуют и во вкладках Альбомы/Исполнители (сначала фильтруют треки, потом группируют).
- [ ] Compilations: если у треков заполнен `AlbumArtist="Various Artists"`, они слились в один альбом; при этом каждый исполнитель виден отдельно во вкладке «Исполнители».
- [ ] Импорт нового `.mp3` с заполненными ID3-тегами Year/Track/AlbumArtist — поля попали в БД (виден корректный год в альбомной плитке, порядок треков в детали альбома).
- [ ] Эталонные треки воспроизводятся (seeder обновил пути под текущий `bin/...`).
- [ ] Рейтинг: выставить 3 звезды на треке — звёзды подсвечиваются. Повторный клик по 3-й звезде — рейтинг сбрасывается в 0.
- [ ] Рейтинг сохраняется: выставить рейтинг, сменить трек, вернуться — рейтинг на месте.
- [ ] Реакция «лайк»: кликнуть ♥ — сердечко загорается красным. Повторный клик — сбрасывается.
- [ ] Реакция «дизлайк»: кликнуть ♥̸ — иконка активируется. Переключение с лайка на дизлайк работает в один клик.
- [ ] Открыть окно «Теги» (`Ctrl+G`): создать тег, переименовать, удалить.
- [ ] Привязать тег к треку через кнопку «+ тег» в средней колонке.
- [ ] Открепить тег через × в секции «Теги» средней колонки.
- [ ] Карточка трека: при ≤ 3 тегах видны все чипы. При ≥ 4 — видны первые 3 + золотая пилюля «+N».
- [ ] Toolbar: тег-чипы отображаются. При узком окне видна кнопка «+ N ещё ▾»; раскрытие popup показывает остальные теги.
- [ ] Toolbar ⋮ popup: фильтр по рейтингу — выставить «не ниже 3★», список сокращается. Кнопка «Сбросить» возвращает все треки.
- [ ] Toolbar ⋮ popup: фильтр по реакции «Лайк» — список показывает только треки с лайком.
- [ ] Комбинированный фильтр: поиск + жанр + тег + рейтинг одновременно — список корректно пересекает все критерии.
- [ ] На дефолтном размере окна в списке треков видно ≥ 7 треков (сравнить с 1.0.2 где было ~4).
- [ ] Апгрейд с 1.0.4: миграция `AddPlaylists` накатилась, рядом с `library.db` появился `library.db.backup-<время>-<id>`, треки/теги/история на месте.
- [ ] Вкладка «Плейлисты» (`Ctrl+4`); старт по-прежнему на «Треки».
- [ ] «+ Новый плейлист» → ввод имени в строке → `Enter` создаёт; пустое имя → «Новый плейлист»; `Esc` отменяет.
- [ ] Правый клик по треку (Треки/альбом/исполнитель) → «Добавить в плейлист ▸ …»; при мульти-выделении добавляются все выделенные.
- [ ] Деталь плейлиста: заголовок с числом треков и длительностью, Play/Shuffle, подсветка играющего, двойной клик играет, `Esc` назад.
- [ ] DnD: трек(и) (в т.ч. `Ctrl`/`Shift`-выделение) на строку плейлиста или в треклист → добавляются в конец; перетаскивание внутри плейлиста меняет порядок, дублей не появляется.
- [ ] «Убрать из плейлиста» убирает именно ту строку (проверить на дубликате трека); «Переименовать» в строке; «Удалить» с подтверждением, треки остаются в библиотеке.
- [ ] Play плейлиста не меняет вкладку «Треки»; пауза/возобновление продолжают плейлист с того же места.
- [ ] Перезапуск: плейлисты и порядок треков на месте.
- [ ] Сбросить выделение (фильтром) во время воспроизведения — `Space` и кнопка Play/Pause продолжают управлять играющим треком.
- [ ] Окно 980×640: панель управления воспроизведением видна целиком, не уходит под прокрутку.

## 3. Сборка установщика

- [ ] Inno Setup 6 установлен (`C:\Program Files (x86)\Inno Setup 6\ISCC.exe`).
- [ ] Запустить:

      ```powershell
      pwsh scripts/build-release.ps1 -Version X.Y.Z
      ```

- [ ] Скрипт прошёл без ошибок, в `release\` появился `MusicBakh-Setup-X.Y.Z.exe`.
- [ ] Размер установщика — в разумных рамках (ожидаем 60–80 МБ при single-file compressed).

Идеально — Windows Sandbox (`WindowsSandbox.exe`) или виртуальная машина / соседская Windows без .NET.

- [ ] Установка `MusicBakh-Setup-X.Y.Z.exe` (SmartScreen → «Подробнее → Выполнить»).
- [ ] Установка per-user в `%LocalAppData%\Programs\MusicBakh`, UAC не запрошен.
- [ ] В «Параметры → Приложения» виден `MusicBakh X.Y.Z`, издатель `Matvey Bakhmatov`.
- [ ] В меню «Пуск» появился ярлык `MusicBakh` с фирменной иконкой.
- [ ] Запуск — окно открывается с правильной иконкой в taskbar и заголовком `MusicBakh`.
- [ ] Эталонные 3 трека видны в библиотеке, обложки подтянулись.
- [ ] Импортирован сторонний `.mp3` — играет, метаданные подтягиваются.
- [ ] После закрытия в `%LocalAppData%\MusicLibrary\` и `%LocalAppData%\MusicBakh\` появились файлы данных.
- [ ] Повторный запуск — состояние сохранилось.
- [ ] Деинсталляция через «Параметры → Приложения»: `{app}` удалён, `%LocalAppData%\MusicBakh\` остался (пользовательские данные).
- [ ] Повторная установка — старая библиотека пользователя подхватилась.

## 5. Публикация

- [ ] Создать аннотированный тег: `git tag -a vX.Y.Z -m "Release X.Y.Z"`.
- [ ] Запушить тег: `git push origin vX.Y.Z`.
- [ ] Создать GitHub Release из тега, прикрепить `MusicBakh-Setup-X.Y.Z.exe`.

## Что не входит в текущий процесс (на будущее)

- **Code signing.** Сертификат не куплен — SmartScreen будет предупреждать. Когда сертификат появится: `signtool sign /tr http://timestamp.digicert.com /td sha256 /fd sha256 /a publish\win-x64\MusicBakh.exe` до запуска ISCC, и повторно тем же `signtool` на готовом `MusicBakh-Setup-*.exe`.
- **Авто-обновление.** Сейчас релиз ручной. При появлении регулярных версий можно посмотреть на Velopack/Squirrel.
- **GitHub Actions.** Сборка ручная — при росте частоты релизов имеет смысл вынести в CI.
- **ARM64.** Только x64.
